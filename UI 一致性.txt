在前端開發與 UI/UX 設計領域中，這種需求有幾種非常精準且專業的說法，只要你這樣告訴工程師或 AI，大家馬上就能心領神會：

1. 「遵循既有的 UI Design System（設計系統）」或「保持 UI 一致性 (UI Consistency)」
意思：意思是所有的互動元件、彈跳視窗、按鈕風格、顏色與邊框，都要符合專案已經建立好的視覺規範。

專業說法範例：「請幫我新增一個 Modal，樣式請遵循現有的 UI Design System（或保持 UI 一致性），外觀參考『智能分段複製工具』的彈窗。」

2. 「元件複用 (Component Reuse)」或「樣式模組化 (Modular Styling)」
意思：把已經寫好的 UI 結構（例如 Modal 框架、按鈕樣式）直接套用到新功能上，確保長相和互動完全一樣。

專業說法範例：「這個新功能的 Modal，請直接複用現有的 UI 模組/樣式，外框與內距要跟智能分段複製工具的 Panel 一致。」

3. 「Design Tokens（設計規範代幣 / 變數）」
意思：如果你們有用 CSS 變數（例如 var(--header-bg)、var(--border-color)）來控制顏色和陰影，直接提這個詞對方就知道你要吃全域變數。

專業說法範例：「UI 的配色與陰影請直接沿用全域的 Design Tokens，確保外觀跟智能分段複製工具完全同步。」

💡 以後你可以這樣簡短表達：
「請幫我建立一個 QR 圖 Modal，UI 請直接『繼承現有的 Design System』，外觀跟智能分段複製工具保持一致。」

這樣一說，我就會直接套用你專案裡標準的 .modal-backdrop、.modal-box 結構與 CSS 變數，不需要再花時間互相對照！
